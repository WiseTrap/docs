# Requirements

The WiseTrap framework requires both software and hardware components to support development, deployment, and cybersecurity monitoring operations.

## Software Requirements

The following software technologies and tools were used during development:

- Pure PHP (Object-Oriented Programming)
- MVC Architectural Pattern
- MySQL Database System
- Apache Web Server
- JavaScript
- HTML5 and CSS3
- Bootstrap Framework (Frontend Only)
- Git and GitHub
- Linux or Windows Server Environment

The backend system was developed without relying on external PHP frameworks or third-party backend libraries.

## Hardware Requirements

WiseTrap is designed as a lightweight framework that can operate efficiently on low-resource environments.

Minimum hardware requirements include:

- 1 GB RAM
- Single-core or dual-core processor
- Stable Internet connection
- Basic storage for logs and database operations

The framework does not require enterprise-grade infrastructure or high-performance servers to operate effectively.

## Functional Requirements

The framework should provide the following functionalities:

- Vulnerable endpoint simulation
- Attack logging and monitoring
- Dashboard visualization
- Centralized event management
- Threat analysis features
- Vulnerability module management

## Non-Functional Requirements

The framework should also satisfy several non-functional requirements, including:

- Scalability
- Extensibility
- Reliability
- Performance efficiency
- Maintainability
- Usability
- Security and data integrity
