# Project Overview

WiseTrap is a web-based credential Honeypot system designed to simulate realistic login environments in order to attract attackers and monitor suspicious activities.  
The project was developed using native PHP OOP with MVC architecture and MySQL database integration.  
The system logs attacker information such as IP address, login attempts, and timestamps while displaying fake data after successful access.  
WiseTrap was deployed on Ubuntu Server and Windows environments using cloud hosting and a public domain to make the platform accessible online.
