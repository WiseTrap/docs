
# WiseTrap Landing Page Overview

The WiseTrap homepage is a simple entry point to the platform. It is designed to guide users to the two main parts of the system:


<img src="/img/HomePage.png" alt="home page" /><br />
---

## 1. Open Endpoint

**URL:** https://honeypot.wisetrap.dev/

This button takes the user to the **main dashboard / control panel**.

Inside the endpoint, users can:
- Access the core application interface
- Work with experiments and system features
- Interact with the backend services provided by WiseTrap
- Use the platform’s main functionality

in short:  
This is the **working area of the platform (Dashboard)**.

---

## 2. Documentation

**URL:** https://docs.wisetrap.dev/

This button opens the **official documentation site**.

The documentation includes:
- Guides and explanations of the platform
- Information about experiments and results
- Setup and integration instructions

In short:  
This is the **learning and reference area (Docs)**.

---

## Summary

The WiseTrap homepage acts as a simple navigation hub:

- **Open Endpoint → Main dashboard (where the system is used)**
- **Documentation → Full technical guide (how the system works)**

This separation helps users clearly distinguish between:
- Using the product
- Learning about the product
