# ER Diagram
The Entity Relationship Diagram (ER Diagram) represents the database structure used within the WiseTrap framework.

The diagram illustrates the relationships between major system entities such as users, attack logs, vulnerability modules, requests, sessions, monitoring records, and other related components.

The database design follows a relational structure that supports efficient data storage, attack tracking, and structured threat analysis.

The ER Diagram helps simplify the understanding of how system entities interact with each other and how cybersecurity-related information is organized within the framework database.

The database architecture was designed to support scalability, maintainability, and efficient query processing while handling large amounts of attack-related data.
