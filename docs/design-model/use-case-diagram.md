# Use Case Diagram
The Use Case Diagram illustrates the interaction between system users and the main functionalities provided by the WiseTrap framework.

The diagram identifies the primary actors involved in the system, including administrators, security researchers, and external attackers interacting with simulated vulnerable services.

The diagram also highlights the core functionalities supported by the framework, such as:

- Managing honeypot modules
- Monitoring attack activities
- Viewing attack logs
- Analyzing collected data
- Managing dashboards
- Reviewing security events

The Use Case Diagram helps provide a clear understanding of user responsibilities and system behavior within the framework environment.
