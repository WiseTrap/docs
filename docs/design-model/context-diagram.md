# Context Diagram
The context diagram provides a high-level overview of the WiseTrap framework and illustrates the interaction between the system and external entities.

The diagram represents WiseTrap as a centralized honeypot framework that communicates with different actors such as administrators, security researchers, and attackers interacting with simulated vulnerable endpoints.

The framework receives malicious requests, processes attack data, stores logs and monitoring information, and presents analysis results through centralized dashboards and monitoring interfaces.

The context diagram simplifies the understanding of the overall system boundaries and demonstrates how external entities interact with the core framework.
